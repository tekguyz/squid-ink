# squid-ink

A bot-free AI meeting notepad. Browser capture of system and mic audio, Gemini
transcription with diarization, and structured note generation under a chosen
persona lens. Next.js App Router, TypeScript, Tailwind CSS v4, Supabase.

Design tokens live in `app/globals.css`. See `CLAUDE.md` for stack and
conventions, `docs/ROADMAP.md` for scope, `docs/DECISIONS.md` for what is
locked, and `docs/KNOWN_GAPS.md` for what is deliberately not built.

    npm install
    npm run dev
